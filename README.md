# 2048 · 方块之间

一个使用原生 HTML、CSS 和 JavaScript 编写的 2048 小游戏，无需安装依赖或构建。

## 开始游戏

直接用浏览器打开 `index.html` 即可。也可以安装 Node.js 后，在项目目录启动本地服务器：

```bash
node server.js
```

然后访问 <http://127.0.0.1:8000>。按 `Ctrl+C` 可停止服务器。

## 玩法

- 使用方向键或 `W`、`A`、`S`、`D` 移动方块；在手机上滑动棋盘也可以操作。
- 每次移动时，相同数字的方块会合并，合并后的数字计入当前得分。
- 合成 **2048** 即可获胜，获胜后仍可选择继续挑战。
- 棋盘填满且没有可合并的相邻方块时，游戏结束。
- 点击“撤销”可以撤回上一次有效移动；点击“新游戏”可重新开始。

最高得分保存在浏览器的 `localStorage` 中。清除该站点的浏览器数据后，纪录会重置。

## 项目文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 响应式布局与方块样式 |
| `app.js` | 游戏规则、输入处理和界面更新 |
| `server.js` | 无额外依赖的本地静态服务器 |

## 浏览器支持

适用于支持现代 JavaScript、CSS Grid 和 `localStorage` 的桌面及移动浏览器。若浏览器禁用了本地存储，游戏仍可运行，但最高得分无法跨次保存。
